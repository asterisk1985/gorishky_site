ТІ САМІ ГОРІШКИ — сайт для VS Code

1. Розпакуйте архів.
2. Відкрийте папку ti_sami_gorishky_site у Visual Studio Code.
3. Запустіть index.html у браузері або скористайтеся розширенням Live Server.

Структура:
- index.html — HTML сторінки
- style.css — стилі й адаптивна версія для телефонів
- images/ — зображення печива, вирізані з наданого макета

Посилання на соцмережі поки загальні. Замініть їх у index.html на свої посилання.
Ціни й умови доставки редагуються в index.html.
Шрифт Nunito підтягується з Google Fonts, якщо є інтернет.
